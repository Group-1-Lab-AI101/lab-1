# lab-1

## Tech Stack

Frontend:

- Framework: React (Vite)
- UI Components: `shadcn/ui`, Tailwind CSS
- Map Rendering: react-leaflet & HTML5 `<canvas>` overlay
- State Management/Routing: React hooks & WebSocket API

Backend:

- Framework: FastAPI (Python)
- Communication: WebSockets (via `starlette`/`websockets`)
- Graph Processing: `NetworkX` with geojson data
- Package Manager: `uv` (Extremely fast Python package installer and resolver)
