# Dataset Description

## Scope

The dataset represents a directed driving network around central Ho Chi Minh
City and 24 tourist landmarks. It is a hybrid dataset: road geometry and road
attributes come from OpenStreetMap, while congestion, risk, traffic profiles,
and one boundary connection are derived or simulated for the lab scenario.

## Source files

The backend stores the final inputs under `data/`:

| File | Description |
| --- | --- |
| `osm/roads.geojson` | 1,075 OSM-derived directed road features |
| `osm/intersections.geojson` | 519 source intersection records |
| `osm/boundary.geojson` | The two source boundary polygons |
| `osm/summary.json` | Generation metadata and source counts |
| `landmarks.json` | 24 named HCMC tourist landmarks |
| `mock_graph.json` | Small group-designed graph for tests/video |
| `mock_config.json` | Example configurable cost weights |

The OSM extraction was generated by the group's `osmnx-tools` repository with
OSMnx 2.1.0 using driving networks from relations `19260504` and `19260546`.
The extraction timestamp in the supplied summary is 2026-07-11T15:19:26Z.

OpenStreetMap data is credited to OpenStreetMap contributors and is available
under the Open Database License. The map UI also displays the required OSM
attribution.

## Final graph

At application load time, road endpoints become graph nodes. Parallel endpoint
pairs retain the faster source feature, major components are connected, and the
largest strongly connected graph is selected.

| Property | Value |
| --- | ---: |
| Routable graph nodes | 481 |
| Directed graph edges | 995 |
| One-way directed edges | 403 |
| Total source road length | 95.083 km |
| Landmarks | 24 |
| Unique landmark nodes | 24 |

## Edge schema

Each runtime edge contains:

- `to`: target node ID.
- `distance_km`: OSM road length converted from meters.
- `time_min`: length divided by parsed/default road-class speed.
- `congestion`: base value from 1 to 4, or up to 5 under a profile.
- `risk`: base road-class penalty from 0.3 to 0.8, increased by rain.
- `road_type`: normalized OSM highway class.
- `metadata`: name, OSM ID, one-way flag, lanes, speed, relation, geometry,
  source values, and any connector/profile flags.

The loader never infers a reverse edge inside an algorithm. Direction comes
from the source features.

## Derived values

Default speed, congestion, and risk depend on road class. Five non-negative
cost presets combine distance, time, congestion, and risk. Three deterministic
traffic profiles are provided:

- `normal`: base values.
- `rush_hour`: higher time and congestion, especially on major roads.
- `rainy`: higher time, congestion, and risk.

These values are controlled experimental scenarios, not live traffic data.

## Landmark assignment

Landmarks use stable ASCII IDs and Vietnamese display names. Each is assigned
to the nearest currently unused routable node, preventing distinct required
stops from collapsing into one graph state. The GUI draws the marker-to-node
offset as a dashed access line.

Mean assignment offset is approximately 100 m. Maximum offset is 383.5 m for
Ben Thanh Market. Access offsets are excluded from road-route totals.

## Assumptions and limitations

- One bidirectional boundary connection (two directed edges) joins separately
  clipped source areas.
- Congestion and risk are simulated from road class and scenario.
- The network does not model traffic lights, turns, vehicle restrictions, or
  real-time incidents.
- A wider continuous OSM extract would reduce landmark offsets and remove the
  boundary-link assumption.
