# Dataset Description

## Scope

The dataset represents a continuous directed driving network around 24 tourist
landmarks in central Ho Chi Minh City. Road geometry and attributes come from
OpenStreetMap, while congestion, risk, and traffic profiles are derived or
simulated for the lab scenario.

## Source files

The backend stores the final inputs under `data/`:

| File | Description |
| --- | --- |
| `osm/roads.geojson` | 3,740 OSM-derived directed road features |
| `osm/intersections.geojson` | 1,713 source and generated access-node records |
| `osm/boundary.geojson` | Continuous landmark bounding box with a 600 m buffer |
| `osm/summary.json` | Generation metadata and source counts |
| `landmarks.json` | 24 landmarks with display and routing-access coordinates |
| `landmark_access_overrides.json` | Curated OSM gates/entrances for 12 landmarks |
| `mock_graph.json` | Small group-designed graph for tests/video |
| `mock_config.json` | Example configurable cost weights |

The extraction is reproducibly generated by
`lab-1-backend/scripts/generate_osm_data.py` with OSMnx 2.1.1. It uses one
continuous bounding box around every landmark plus a 600 m buffer, avoiding
the coverage gaps caused by separately clipped administrative relations.

OpenStreetMap data is credited to OpenStreetMap contributors and is available
under the Open Database License. The map UI also displays the required OSM
attribution.

## Final graph

At application load time, road endpoints become graph nodes. Parallel endpoint
pairs retain the faster source feature, major components are connected, and the
largest strongly connected graph is selected.

| Property | Value |
| --- | ---: |
| Routable graph nodes | 1,662 |
| Directed graph edges | 3,649 |
| One-way directed edges | 1,133 |
| Directed source road geometry | 331.591 km |
| Landmarks | 24 |
| Unique landmark nodes | 24 |

## Edge schema

Each runtime edge contains:

- `to`: target node ID.
- `distance_km`: OSM road length converted from meters.
- `time_min`: length divided by parsed/default road-class speed.
- `congestion`: base value from 1 to 4, or up to 5 under a profile.
- `risk`: base road-class penalty from 0.3 to 0.8, increased by rain.
- `road_type`: normalized OSM highway class.
- `metadata`: name, OSM ID, one-way flag, lanes, speed, relation, geometry,
  source values, and any connector/profile flags.

The loader never infers a reverse edge inside an algorithm. Direction comes
from the source features.

## Derived values

Default speed, congestion, and risk depend on road class. Five non-negative
cost presets combine distance, time, congestion, and risk. Three deterministic
traffic profiles are provided:

- `normal`: base values.
- `rush_hour`: higher time and congestion, especially on major roads.
- `rainy`: higher time, congestion, and risk.

These values are controlled experimental scenarios, not live traffic data.

## Landmark assignment

Landmarks use stable ASCII IDs and Vietnamese display names. The display
coordinate remains at the venue center. A separate routing coordinate denotes
a curated gate/entrance or a generated nearest-road access point. During data
generation the nearest directed road edge is split at the projected access
position, so routes can end mid-block instead of at an arbitrary intersection.

The mean access-to-road offset is 8.0 m and the maximum is 29.9 m at the Central
Post Office. The loader rejects regenerated data when any access point exceeds
75 m. The GUI distinguishes the green venue-center marker from the amber access
marker and draws the remaining connector explicitly.

## Assumptions and limitations

- Twelve access points are curated from current OSM gate/entrance nodes or
  verified building frontage; remaining landmarks use nearest-road access.
- Congestion and risk are simulated from road class and scenario.
- The driving network does not include pedestrian-only paths inside parks or
  venues; a future walking mode should use a separate `walk` graph.
- The network does not yet model turns, traffic signals, vehicle classes, or
  real-time incidents.
